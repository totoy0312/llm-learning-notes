## 新增一篇笔记的模板

建一个文件夹，比如 `papers/论文短名/notes.md`，内容大致包含：

```markdown
# 论文标题

> 精读 / 略读笔记 · 日期

## 基本信息
- 论文 / 会议 / 作者
- 论文链接 / 官方代码

## 研究问题
（它要解决什么、为什么值得做）

## 核心思路
（方法骨架，用自己的话）

## 实验与结论
（主结果 + 关键数字）

## 我的理解与疑问
（读懂的、没读懂的、批判）

## 复现状态
（跑没跑通、卡在哪）
```

然后在主 README 的「论文笔记」表里登记一行。
