# SHOT: Do We Really Need to Access the Source Data? Source Hypothesis Transfer for Unsupervised Domain Adaptation

> 略读笔记 · 2026-10-29

## 基本信息

- 论文：Do We Really Need to Access the Source Data? Source Hypothesis Transfer for Unsupervised Domain Adaptation
- 会议：ICML 2020 · PMLR 119
- 作者：Jian Liang、Dapeng Hu、Jiashi Feng
- 核心方法：SHOT（Source HypOthesis Transfer）
- 论文链接：https://proceedings.mlr.press/v119/liang20a.html
- 官方代码：https://github.com/tim-learn/SHOT

## 研究的核心问题

如果拿不到源域的训练数据，只拿得到训练好的源模型，能不能让它适应新的目标域？

注意：**拿不到源域数据，不代表拿不到源模型。**

## 背景：UDA 与 source-free 设定

- UDA：利用从有标注源数据集中学到的知识，解决新的、没有标注数据的目标领域中的类似任务。源域有标签，目标域没有标签，不能直接拿目标域的标准答案来训练。
- 常规 UDA：源域数据 + 目标域无标签数据。
- 本文的 source-free 设置：训练好的源模型 + 目标域无标签数据。算法不能在适应阶段重新查看源域的原始样本。

## SHOT 的核心思想

特征提取器（把图片转化为模型可以理解的特征）+ 分类器（根据特征预测类别）。

SHOT 的关键操作：

1. **冻结分类器**：保留源模型已有的分类知识，不更新分类器参数。
2. **调整特征提取器**：用目标域无标签数据更新特征提取器，使提取出的特征更适合原来的分类器。
3. **利用目标域自身的信息学习**：通过信息最大化和伪标签机制，让模型逐渐形成更有区分度的目标域特征。

注意：冻结分类器不等于整个模型不训练。SHOT 的核心是**固定分类器、训练特征提取器**。

## 信息最大化（IM）

告诉模型应该形成怎样的预测分布：在目标域上，单个样本的预测尽量确定（熵低），整个目标域的数据又不要全部被预测成同一个类别（保持多样性）。

把单个样本的熵和整体预测的熵结合起来——信息最大化的核心：**单个样本的预测要确定，整体预测又不能过度集中在少数类别。**

## 自监督伪标签（ST）

伪标签不是人工标注的真实答案，而是模型根据现有信息产生的训练目标。SHOT 的伪标签机制利用目标域的特征结构：

1. 用当前模型提取目标域样本的特征。
2. 根据样本的预测结果，将样本划分到不同的类别。
3. 计算各类别的特征中心，即类别原型（class prototype）。
4. 根据样本与各类别原型的距离，重新判断样本可能属于哪个类别。
5. 用更新后的伪标签辅助训练特征提取器。

注意：不是说离哪个中心近，就一定属于哪个类别。

## 局限

1. **依赖源模型已有的知识**：SHOT 不是从零开始学习，依赖源模型提供有分类能力的分类器；若源模型知识有严重缺陷或域差过大，固定分类器可能无法提供可靠判断。
2. **伪标签可能出现错误累积**：伪标签由模型自身产生，持续生成错误伪标签会强化错误的特征结构。
3. **类别分布假设可能不适用**：信息最大化的多样性目标鼓励预测分布分散，目标域类别分布严重不均衡时可能与真实分布不一致。
4. **实验领域与研究方向存在差距**：论文研究视觉域自适应，与 Transfer Learning + LLM 方向有距离，迁移价值需谨慎看待；且发表于 2020 年，适合作为经典方法学习。
